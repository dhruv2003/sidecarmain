# Sidecar — Brand Assets Pack

Logo exports for Sidecar, the local AI companion.

## The mark

**Split Pane**: a main pane with a narrow pane docked beside it. The main pane is your editor or app; the narrow one is Sidecar running next to it. The mark is drawn on a 48-unit grid (main pane 26×30 with radius 6, side pane 9×30 with radius 4.5, 3 units apart) and contains no text, so it stays legible at 16px in a tray, dock or favicon.

All SVGs are generated by `docs/make_svgs.py` (the wordmark is converted to outlines from Geist SemiBold, so no font is needed to open them).

## Core files

- `svg/sidecar-symbol.svg`: primary symbol (cobalt + charcoal), transparent
- `svg/sidecar-symbol-reversed.svg`: for dark backgrounds (cobalt + white)
- `svg/sidecar-symbol-black.svg` / `white.svg`: monochrome
- `svg/sidecar-lockup-light.svg` / `dark.svg`: horizontal lockup
- `svg/sidecar-wordmark-black.svg` / `white.svg`: wordmark only, lowercase "sidecar"
- `svg/sidecar-app-icon-light.svg` / `dark.svg` / `blue.svg`: app icon masters

## Raster exports

`png/` holds 1024, 512, 256, 180, 128, 64, 48, 32 and 16 px exports of the app icons, plus 1024 px symbols, lockups and wordmarks.

## Colors

- Cobalt `#3155FF` (use `#4D6BFF` on dark surfaces)
- Charcoal `#0C0E13`
- Off-white `#F7F8FA`
- White `#FFFFFF`
- Status: ready `#3CCF91`, pending `#F0B54A`, error `#FF6B7A`

## Type

Geist for the interface and wordmark, Geist Mono for keys, IDs, endpoints and logs. Both are bundled with the app under the SIL Open Font License.

## Usage

Keep clear space around the mark equal to the gap between its two panes. Don't stretch it, outline it, or add shadows or gradients. Keep the side pane narrower than the main pane; that relationship is the logo.
